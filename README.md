# Analyse de l'avantage à domicile dans le football professionnel
 Projet en cours

## Objectif
Estimer un modèle logit pour expliquer la probabilité de victoire à domicile en Premier League et en Ligue 1, avec un focus sur l'impact du huis clos pendant la période Covid.

## Données
- Premier League, 5 saisons (2017/2018 → 2021/2022)
- 1 848 matchs

## Outils
- Python — nettoyage des données, modèle logit, visualisations
- R — visualisations ggplot2

## Résultats préliminaires
- Taux de victoire domicile : 43.8%
- Taux de victoire COVID: 40.3%
- Taux de victoire sans COVID: 45.1%
- Effet huis clos Covid : −5pp (significatif à 5%)
- Principal déterminant : écart au classement
